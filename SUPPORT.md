# Support

Pulse is experimental and does not currently offer a production support SLA.

- Use [GitHub Discussions](https://github.com/mburakmmm/pulse/discussions) for
  design and usage questions when Discussions is enabled.
- Use the appropriate [issue template](https://github.com/mburakmmm/pulse/issues/new/choose)
  for reproducible defects or scoped feature proposals.
- Read [`docs/compatibility.md`](docs/compatibility.md) before reporting a
  compiler, backend or platform problem.
- Report security and privacy issues privately according to
  [`SECURITY.md`](SECURITY.md).

Please include the Pulse commit, `noxc version --build-info`, backend, operating
system and a minimal synthetic reproducer. Do not include production telemetry or
secrets.
