# Code of Conduct

Pulse contributors are expected to keep project spaces respectful, technical
and safe for participation.

## Expected behavior

- Give and receive specific, evidence-based feedback respectfully.
- Assume good intent while remaining clear about correctness and safety.
- Welcome different experience levels, backgrounds and viewpoints.
- Keep disagreements focused on designs, code and observable behavior.
- Protect confidential reports, credentials and personal information.

Harassment, discrimination, threats, sexualized conduct, deliberate disruption,
doxxing and publication of private security reports are not acceptable.

Maintainers may edit or remove content, close interactions, temporarily restrict
participation or permanently ban participants when necessary to protect the
project. Report conduct concerns privately through the repository owner's GitHub
profile. Reports will be handled as confidentially as practical; no fixed SLA is
claimed.
